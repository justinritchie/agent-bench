Method

  • priority = 0.5*public_norm + 0.3*own_success + 0.2*speed_rank: weights public 0.5, own success 0.3, speed 0.2; every input is 0–1.
  • Public: each class metric is min-max scaled across the engine/model pairs ranked here, then averaged; 0.5 when a model has none.
  • Harness discount: a score measured in another agent's harness counts at 0.8× (marked ×0.8), for example a Terminal-Bench run in Claude Code credited to Antigravity running the same model. The engine's own harness, or a model-only benchmark, counts in full.
  • Own success: share of own jobs in the last 28 days that finished; 0.5 with fewer than 10 jobs. Speed: rank by own median minutes, else Artificial Analysis output speed, else 0.5.
  • Evidence before quota: scores within 0.03 tie (marked tie) and go to more own jobs, then more remaining quota, then speed. An unproven entry ranks above a proven one only on a clear public margin: more than 0.03 ahead and a higher public score (else marked evidence). Never on quota alone.
  • Gate: an engine at or above 95% weekly usage on every seat that serves the model is gated: listed last, not ranked.
  • Only aggregate job counts, success rates and median minutes are published. Model lists for Grok CLI are unverified.

Notes

  • Own outcomes cover Claude Code and Codex CLI jobs only; Antigravity and Grok jobs are not logged yet, so their own_success is the 0.5 default.
  • Codex jobs that do not record a model are counted under the Codex default model.
  • Grok CLI has no plan-usage reading (per-session cost only), so it is never gated.
  • Gemini 4 Argon leads Arena text but is not ranked: `agy models` does not list it.
  • Grok CLI model names come from `grok models` and are unverified: no Grok job has run.
